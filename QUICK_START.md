# AI Movie Studio - Quick Start for Claude Code Agent

## 🎯 Mission
You are connected to the ARC system with an **NVIDIA A100 GPU**. Your task is to **activate the AI generation capabilities** of this application by implementing the Phase 5 providers.

The entire application (Frontend, Backend, Database, Intelligence Layer, Infrastructure) is **already built**. You only need to connect the actual AI models.

---

## 🚀 Immediate Action Plan

### 1. Verify Environment (Run These Commands)
```bash
# Check GPU
nvidia-smi

# Navigate to project
cd /workspace

# Check existing structure
ls -la

# Start infrastructure (DB, Redis)
docker-compose up -d postgres redis

# Wait 10 seconds, then check logs
docker-compose logs -f
```

### 2. Review the Architecture
Read these files first to understand the contracts you must implement:
- `backend/app/providers/base.py` (Abstract Interfaces)
- `backend/app/services/orchestrator/engine.py` (Task Dispatcher)
- `backend/app/gpu/manager.py` (GPU Memory Handler)

### 3. Implement Providers (In Order)

#### A. Image Provider (FLUX.1)
Create: `backend/app/providers/flux_provider.py`
```python
from app.providers.base import ImageProvider
# Implement the generate() method using diffusers library
```

#### B. Video Provider (CogVideoX or Wan)
Create: `backend/app/providers/cogvideo_provider.py`

#### C. Voice Provider (XTTS)
Create: `backend/app/providers/xtts_provider.py`

#### D. Render Engine
Create: `backend/app/services/rendering/ffmpeg_renderer.py`

### 4. Update Dependencies
Add to `backend/requirements.txt`:
```txt
diffusers
transformers
accelerate
torch
torchaudio
torchvision
xformers  # For A100 optimization
coqui-tts  # For XTTS
ffmpeg-python
```

### 5. Configure Environment
Create `backend/.env`:
```env
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/ai_movie_studio
REDIS_URL=redis://localhost:6379/0
JWT_SECRET=dev-secret-key-change-in-prod
STORAGE_PATH=/workspace/storage
MODEL_CACHE_PATH=/workspace/models
GPU_DEVICE_ID=0
DEBUG=True
```

### 6. Run Migrations & Start
```bash
cd backend
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

In another terminal:
```bash
cd backend
celery -A app.workers.celery_app worker --loglevel=info --pool=solo
```

### 7. Test End-to-End
1. Open browser: `http://localhost:3000` (ensure frontend is running)
2. Login/Register
3. Create Project: "Sci-fi movie on Mars"
4. Click "Generate Blueprint" (Phase 3 - Already works)
5. Click "Render Movie" (Will now trigger your Phase 5 providers)
6. Watch progress in Real-time via WebSocket

## ⚠️ Critical Rules

1.  **DO NOT** modify `orchestrator` or `worker` core logic.
2.  **DO** implement the `Provider` interfaces only.
3.  **DO** use `GPUManager` for all model loading/unloading.
4.  **DO** save outputs to `STORAGE_PATH` defined in `.env`.
5.  **DO** update task status via the provided `TaskUpdater` utility.

---

## 🆘 If You Get Stuck

1.  **Check Logs:** `docker-compose logs -f worker`
2.  **Check GPU:** `watch -n 1 nvidia-smi`
3.  **Check DB:** `docker-compose exec postgres psql -U postgres -d ai_movie_studio`
4.  **Restart Queue:** `docker-compose restart worker`
